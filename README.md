# Observatorio Porsche 911 (996) — Evolución de Mercado (1998–2026)

Aplicación web estática interactiva con la evolución histórica de cotización europea de los 8 modelos emblemáticos de la generación **Porsche 911 (996)**, diferenciando las fases **996.1** y **996.2**.

## Contenido del paquete
- `index.html`: Aplicación completa (HTML + CSS + JS con Chart.js vía CDN).
- `img/`: Las 8 fotografías de estudio en alta resolución:
  - `carrera-996-1.jpg` — 911 Carrera / Carrera 4 996.1 (Azul Lapis)
  - `carrera-996-2.jpg` — 911 Carrera / Carrera 4 996.2 (Plata Polar)
  - `c4s.jpg` — 911 Carrera 4S Coupé (Plata Ártico)
  - `40jahre.jpg` — 911 40 Jahre 911 (Plata GT)
  - `turbo.jpg` — 911 Turbo (Negro Basalto)
  - `gt3mk1.jpg` — 911 GT3 996.1 (Rojo Guardia)
  - `gt3mk2.jpg` — 911 GT3 996.2 (Amarillo Speed)
  - `gt3rs.jpg` — 911 GT3 RS (Blanco Carrara / Rojo)

## Cómo publicarlo gratis en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo, `porsche-996-valoracion`) marcado como **Public**.
2. Sube el archivo `index.html`, `README.md` y la carpeta `img/` completa a la raíz del repositorio (**Add file → Upload files**).
3. Entra en **Settings → Pages** dentro de tu repositorio.
4. En **Build and deployment → Source**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y pulsa **Save**.
5. En 1–2 minutos GitHub te dará tu enlace público (`https://tu-usuario.github.io/porsche-996-valoracion/`).
